# Critique

## Source checks

- Check component boundaries and copy for generic, unrelated-product structure.
- Confirm every `DESIGN.md` requirement maps to named components or tokens.

## Computed checks

- Judge whether the primary action is findable within seconds from rendered prominence.
- Check information architecture and cognitive load from measured layout and tab order.
- Flag crowds of primary choices and unchunked data with rendered evidence.
- Compare density and typography against `DESIGN.md` when present.
- Check visibility of system status, user control, error prevention, recognition over recall, and help.
- Flag hidden state and working-memory load.
